# bruhgrow tools for Mac

Every image and PDF tool in one native Mac app. Works offline, so your files never leave your Mac.

**[Download the latest version](https://github.com/mdanassaif/bruhgrow-releases/releases/latest/download/bruhgrow-tools.dmg)**

- Requires a Mac with Apple silicon (M1 or later)
- Signed and notarized by Apple
- Activate with your lifetime license from [bruhgrow.com](https://bruhgrow.com/plans)

This repository only hosts the app downloads.
